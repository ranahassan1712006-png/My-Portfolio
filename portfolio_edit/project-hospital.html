Hospital Management System

A complete desktop Hospital Management System developed with a team, combining software development, UI design, documentation and presentation.

C#.NET 6WinFormsOOPGit / GitHub

The project

The system was developed as a complete academic project rather than only a coding task. The work included a proposal, pseudocode, interface design, implementation and final presentation.

What I worked with

The project used C# with .NET 6 and Windows Forms. Core software concepts included OOP, inheritance, enums, file handling and input validation.

Main functionality

The system covers patient registration, doctor schedules, medical appointments and administrative operations. Appointment availability logic was designed to prevent double-booking.

Why it matters

This project demonstrates my ability to work within a team, move from requirements to implementation, and communicate a technical solution clearly.

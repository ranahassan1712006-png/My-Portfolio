Course Reservation Database System

A MySQL database project built around courses, students and reservations, with relational design and practical SQL reporting.

MySQLSQLER DiagramDatabase Design

The project

The system manages courses with limited capacity and student reservations across different dates and times.

Database design

The project included related tables for students, courses and reservations, with primary keys, composite relationships, foreign keys and constraints.

SQL work

Queries were created for course popularity, upcoming courses, maximum and minimum prices, active registrations, student registrations and reporting.

Business logic

One requirement applied a 30% price discount to courses whose reserved positions were between 25% and 50% of capacity, encouraging additional reservations.

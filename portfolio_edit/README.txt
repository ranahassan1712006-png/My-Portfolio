HOW TO ADD IMAGES
-----------------
1. Create/use the "images" folder.
2. Rename your images exactly as above.
3. Put one image per file.
4. Open index.html in your browser.

If your image is PNG instead of JPG, either rename the file to .jpg
only if it is actually a JPG, OR change the matching .jpg reference
inside the HTML to .png.
